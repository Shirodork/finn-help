01

Everyday commands

Finn, stream information, games, and community favorites.

Everyone #

Help

Open the topic list or ask about one command directly.

!help !help <topic or command> <command> help
Everyone #

Finn's memories

See what Finn remembers about you, or another viewer when that option is enabled.

Stream status

Check how long the stream has been live or view the latest stream summary.

!uptime !streamstats

Alias: !laststream

Everyone #

Fun and games

!8ball <question>
Ask the magic 8-ball.
!ship <user1> [user2]
Get a just-for-fun compatibility score. One name pairs you with them.
!pick <a, b, c>
Let Finn choose. With no options, he picks from recent chatters.
!coinflip
Flip a coin. Alias: !flip.

Shoutouts

Share another creator's Twitch channel with chat.

!so <user>

Varies #

Channel-specific commands

The channel may add more commands over time. Use !help custom for an explanation, and ask a moderator what is currently available.

02

Quotes

Revisit memorable moments or add a new one.

Everyone #

Find a quote

!quote
Show a random quote.
!quote <number>
Show one quote by number.
!quote latest
Show the newest quote.
!quote count
Count all saved quotes.
!quote search <words>
Find quotes containing those words.
!quote info <number>
See who added it, when, and during which game.
Permission varies #

Add a quote

The channel decides who can add quotes.

!quote add <text>
Moderator #

Remove a quote

Delete a quote by number. Its old number is not reused.

!quote remove <number>

Aliases: delete, del

03

Song requests

Request music, check the queue, and fix the occasional wrong pick.

Song requests may be open or closed during a stream. Finn will tell you the current state when you use a request command.
Everyone* #

Request a song

Paste a YouTube link or search by song and artist.

!sr <link or search>

Example: !sr Take On Me a-ha

Aliases: !songrequest, !songreq

*The channel may set a follower, subscriber, VIP, or moderator requirement.

Everyone #

Now playing and queue

!current
Current song and requester. Aliases: !song, !nowplaying, !np.
!queue
Queue size and the next few songs. Aliases: !songlist, !sl.
!when [user]
Your position and estimated wait. Aliases: !eta, !wait.
Everyone #

Request tools

!wrongsong
Remove your newest queued request. Aliases: !ws, !oops.
!voteskip
Vote to skip the current song. Alias: !vs.
!replay
Request the previously played song again. Alias: !again.
Everyone #

Song history and stats

!lastsong
Previously played song. Aliases: !previous, !prev.
!played
Recently played songs. Aliases: !songhistory, !recent.
!songstats [user]
Song totals for this stream and all time. Alias: !srstats.
!srtop
Most-requested songs. Alias: !topsongs.
Everyone #

Song command help

!srhelp !sr help

Aliases: !srcommands, !mediahelp

Moderator #

Manage channel commands

Use !commands help <action> for focused syntax in chat.

!commands [list]List commands
!commands info <name>Show settings
!commands add <name> <reply>Create
!commands edit <name> <reply>Change reply
!commands remove <name>Delete
!commands enable|disable <name>Toggle
!commands cooldown <name> <seconds>Channel cooldown
!commands usercooldown <name> <seconds>Per-user cooldown
!commands modbypass <name> <on|off|default>Cooldown bypass
!commands userlevel <name> <level>Minimum access
!commands replytype <name> <say|mention|reply>Reply style
!commands alias add|remove <name> <alias>Manage aliases
!commands keyword add|remove <name> <phrase>Manage phrase triggers
!commands counter get|set <name> [value]Manage counters
Show shorter action aliases

remove: rm, delete

cooldown: cd

usercooldown: ucd, usercd

modbypass: modskip

userlevel: level

replytype: reply

alias: aliases

keyword: keywords

counter: counters

Inside alias and keyword, remove also accepts rm.

Moderator #

Manage recurring messages

Use !timers help <action> for focused syntax in chat.

!timers [list]List timers
!timers info <name>Show settings
!timers add <name> <message>Create
!timers edit <name> <message>Change message
!timers remove <name>Delete
!timers enable|disable <name>Toggle
!timers interval <name> <minutes>Set frequency
!timers minlines <name> <count>Require chat activity
!timers command <name> <command|none>Mirror a command
Show shorter action aliases

remove: rm, delete

interval: int

minlines: minline

command: cmd

To stop mirroring a command, use none, off, clear, or message.

!promote <fact-id> <canonical text>Mark established lore
!demote <fact-id>Return lore to an observation
!phase [name|next|list]View or change the stream phase

QUICK CHECK

No reply?

  • The feature may be turned off for this stream.
  • A cooldown may still be running.
  • The command may need a subscriber, VIP, moderator, or broadcaster.
  • A channel-specific command may use the same name.
  • Try !help <command> to see the current guidance.

No matching commands

Try a shorter word, an alias, or clear the current filters.
