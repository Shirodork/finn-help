BEFORE USING CONTROLS

Enable deliberately. Arm separately.

1

Check the microphone

Use the updated, authenticated operator microphone. Begin with “Hey Finn” or the channel's configured wake phrase. A normal question still uses ordinary conversation.

2

Choose permissions and arm

Open the private dashboard's Voice Controls tab. Voice controls and optional bookmark, song-skip, playback, quiet, takeover, recorded-break return and stream-preset permissions must be enabled separately. Enable return before starting the break. Enabling does not arm anything; explicitly arm the current microphone session.

3

Respect confirmation

Night Sky changes, enabled media/quiet actions and approved stream presets/restoration use the configured second-confirmation preference. Bookmarks are immediate and skip only that extra confirmation.

4

Protect the room

Authentication identifies the microphone, not the speaker. Anyone audible to an armed mic may request a supported action. Use isolated audio/headphones and disarm outside intentional use.

01

What can I say?

One clear request after the wake phrase. Wait for Finn to finish speaking before replying.

These are supported commands in the released code, not a promise that a channel has deployed or enabled them. Spoken controls retain arming, lifecycle and action-specific safety checks.

Night Sky Protocol

Hey Finn, activate night sky protocol.Hey Finn, end night sky protocol.Hey Finn, night sky protocol status.

Start or end the configured Protocol using the operator's confirmation preference. Status reports without changing it; spoken status still requires arming.

“Hey Finn, could you please activate Night Sky Protocol for me?” is also supported. Optional AI interpretation can help with other wording, but does not grant permission or execute arbitrary tools.

Confirm or cancel

Hey Finn, confirm that.Hey Finn, cancel that.

Confirm only the current unexpired proposal. Cancel pending or unstarted work; it is not rollback for a change already sent. Existing “confirm night sky” and “cancel night sky” wording remains supported.

Use a fresh wake for confirmation or a full corrected request. Bare “yes,” “on” or “off” cannot confirm a proposal or change a setting through the conversational window.

Night Sky + Finn takeover

Hey Finn, activate Night Sky and take over.Hey Finn, I'll be right back, activate Night Sky and take over.

Separately enable this routine in Voice Controls; it defaults OFF. It checks both services before changing anything, ensures Night Sky is on, then engages Finn's existing AFK mode. One confirmation covers the whole plan when confirmation is enabled.

AFK may start Finn's autonomy, use the configured event-reaction mode and post the normal handoff announcement. Maple is unchanged. Natural surrounding chatter needs natural interpretation Enabled; the complete exact first example uses the free parser.

The dashboard shows each step. Both steps share the original 30-second completed-request deadline. If the second step fails or you cancel midway, a completed first step is left alone and reported; there is no automatic undo or restart replay. Check both states before trying again.

Night Sky alone does not start AFK. Ending only Night Sky does not end AFK. Its separately enabled recorded-break return below is the sole return combination; reversed order, AFK-only, extra/unknown steps and quoted/conditional/corrected requests remain unsupported.

Welcome back from your recorded break

Hey Finn, I'm back.Hey Finn, restore my break.

Enable “Return from recorded break” separately in Voice Controls before starting Night Sky + Finn takeover. Finn remembers what that routine actually turned on. He returns from owned AFK first, then uses the normal Night Sky scene, reward and music restore. Your existing confirmation choice still applies to the whole return.

Anything already on before the break stays on. Later manual changes or replacement runs are preserved; a conflicting reward/provider state may need dashboard recovery. If a constellation is still playing, Finn waits for it before reporting restoration complete.

This needs a fresh wake, armed microphone and current permissions. The original 30-second request deadline still applies. The record is not chat-history memory and does not survive a bot restart or stream end. No recorded owned break means no changes; use existing AFK/Night Sky controls. It is not arbitrary undo. A mic reconnect requires a fresh arm and wake.

Private stream bookmarks

Hey Finn, bookmark that.Hey Finn, bookmark that: the project is finished.

With bookmark permission and arming, save a private Scrapbook moment immediately during a real active stream. The optional note stays private and is not read aloud in the acknowledgement.

The timestamp is when the completed request is admitted, not an inferred earlier highlight. An uncertain save may offer an explicit same-bookmark retry for the original short window; after expiry or restart, inspect Scrapbook. No automatic retry.

Approved stream presets

Hey Finn, start the Starting Soon routine.Hey Finn, start Crafting Focus.Hey Finn, start the Wrap-up routine.Hey Finn, restore my stream routine.

Review these presets in Voice Controls, refresh routine status and use “Enable routines” for new runs, then separately enable “Voice approved stream routines.” It defaults OFF. Use your authenticated, armed microphone and a fresh wake during a detected live stream. Enabling a switch never starts a preset.

Starting Soon defaults to starting-soon conversation context and ten minutes of Finn-only quiet. Crafting Focus defaults to main-stream context and 25 minutes of quiet. Wrap-up defaults to outro context and keeps the current quiet setting. Your operator can configure those effects.

These change conversation context and unsolicited Finn comments—not OBS scenes, music, direct answers, Maple or DnD. Wrap-up does not end the stream, and Starting Soon requires the stream already detected live. Offline/LAB testing alone does not authorize a run. The standalone quiet-command permission is not needed for a reviewed preset's effects.

With confirmation enabled, review the proposed changes, then say “Hey Finn, confirm that.” With it disabled, a valid fresh request applies after checks. Exact phrases use the free parser; optional natural interpretation may select only a supported preset, not invent steps or undo targets.

One active record is shared with the dashboard. Restore changes only phase/quiet still owned by that run, preserves later manual choices and keeps an old quiet timer's original deadline. It is not arbitrary undo. Turning the main routine switch OFF blocks new runs but still allows owned restoration with voice permission ON in the same live stream. Stream end/restart forgets the record; there is no automatic replay or retry.

The original 30-second completed-request deadline covers interpretation, confirmation and execution. “Cancel that” cancels pending work, not applied effects. “I'm back” still means the separate Night Sky/AFK recorded break. Wake-free conversation, extra commands and unknown presets cannot authorize these changes. Check dashboard state after an uncertain result.

Skip, pause or resume music

Hey Finn, skip this song.Hey Finn, pause the music.Hey Finn, resume the music.

Song skip and playback each need their own permission. These requests use configured confirmation and target the original captured media occurrence, never a replacement song.

During Night Sky, only ambient music changes; the held normal song and viewer queue remain untouched. Acceptance is not proof of audible playback. Check the media dashboard on uncertainty before making a fresh request; there is no automatic retry.

Temporarily quiet Finn comments

Hey Finn, stay quiet for five minutes.Hey Finn, resume your comments.

With quiet permission and configured confirmation, suppress Finn's unsolicited comments for 1–60 whole minutes. Bare “stay quiet” means five minutes. A new accepted request replaces the deadline from now, rather than adding time.

Direct answers, other speakers, music, notifications, maintenance and requested performances remain available. Already-playing speech may finish. Resume clears only temporary quiet; it never enables saved autonomy.

Use the private dashboard

The dedicated Voice Controls tab brings together action status, permissions, arming, pending proposals, phrase tests and searchable command help. The quiet countdown has a clear-only “Resume Finn comments” button usable without arming.

Night Sky Protocol reward, music and OBS setup stays in Night Sky. Use the shortcuts between the two tabs; changing tabs never enables, arms or executes an action.

Disarming alone leaves an accepted quiet timer intact. Quiet expiry, resume, disabling its permission, stream end, a new session or restart clears it without replaying old comments.

Media, quiet, takeover, recorded-break return and stream-preset/restore proposals expire within the original 30-second completed-request window; later interpretation or confirmation cannot extend it. Check status rather than treating a slow HTTP reply as success or failure.

02

Keep the conversation flowing.

A short, optional chance to reply without repeating “Hey Finn.”

Follow-up conversation is OFF by default and separate from operator actions. Enabling it does not arm controls or open the microphone window immediately.

Enable the separate switch

In the private dashboard's Voice Controls tab, use “Enable follow-up listening.” No action arm is needed for ordinary conversation. Begin with a deliberate “Hey Finn” question.

Requires the updated, authenticated microphone client, with the operator's shared server token configured. Refresh Finn's OBS browser source after updating so its current playback reports are available. Older clients still need the wake phrase for each question.

Six usable listening seconds

Hey Finn, what do you think of these colors?And what about the blue ones?

The window opens only after Finn's direct spoken answer naturally finishes, echo protection settles and the microphone is ready. The dashboard shows “Follow-up available” with a countdown. Begin speaking before it ends; a verified in-window utterance may finish afterward, within the recording limit.

No window follows unsolicited comments, operator-action acknowledgements, skipped/failed replies or text-only answers. Other Finn, Maple or DnD speech closes the opportunity. This is not interrupting Finn while he talks.

Conversation only

Ask another question or keep bantering. To change Night Sky, music or quiet settings, select/restore a stream preset, save a bookmark, or confirm an action, say a fresh “Hey Finn” and follow the usual permission, arming and confirmation rules.

An action-shaped follow-up gets a reminder to use the wake phrase, not permission to act. Authentication identifies the microphone, not who is speaking; room or chat-directed speech during the window can be mistaken for a follow-up. Use isolated audio/headphones and disable the feature if it gets in the way.

Finish when you want

That's all.Thanks, that's all.

Those phrases close an open conversation locally, without another model reply. Or use “End conversation” in Voice Controls; it does not need action arming. F11/privacy mute, microphone disconnect, Stop/Clear, history/persona/lifecycle changes or disabling follow-ups also end further listening.

Defaults: six seconds per window, at most three follow-up turns and 180 seconds overall. These limits are configurable. Expiry or End conversation does not cut off a valid reply already playing. A new deliberate wake begins a fresh exchange.

03

Answer the choice Finn offered.

One short answer to one Night Sky question—not a new command.

Scoped clarification is OFF by default and independent of follow-up conversation. Enable it separately in Voice Controls. Operator controls must be armed and natural interpretation enabled.

Wait for the question to finish

Hey Finn, Night Sky?On, please.

If Finn safely understands that you mean Night Sky but not whether to start or end it, he may ask “Do you want Night Sky on or off?” Wait for the separate answer countdown, then say “on” or “off.” Optional “please” is fine.

The window opens only after that exact question naturally finishes, echo protection settles and the authenticated microphone is ready. Default: six seconds to begin. A skipped, failed or unheard question never opens one.

A choice is not confirmation

With confirmation enabled, choosing “on” selects the original request but does not start Night Sky. Use a fresh “Hey Finn, confirm Night Sky” when prompted. With the operator's explicit no-confirmation mode, a valid choice may apply that original request.

The original 30-second completed-request deadline caps the question, answer and confirmation. It never restarts when you answer. Generic “yes,” new commands, conflicting answers and multiple actions are not accepted choices.

One answer, then move on

One complete answer consumes the opportunity. Invalid or expired answers need a fresh full request. “Cancel clarification” closes it without arming, confirming or undoing an action already started.

Privacy mute, Stop/Clear, microphone or lifecycle changes, other co-host speech and a new “Hey Finn” close the old offer. This first feature handles Night Sky on/off only. Ordinary conversational follow-ups still cannot execute actions.

HELP

Ask what Finn can do

Learn the difference between a supported control and one ready to use.

Get the short tour

Hey Finn, what can you do?

Finn can explain his shipped operator voice controls, their permissions and current local prerequisites. This is a limited voice-control guide, not a list of every feature.

Ask about one area

Hey Finn, what do I need to enable to let you control music?Hey Finn, can you save stream bookmarks?

Get setup guidance without enabling, arming, confirming or running anything. Help does not replace or extend a pending action. “Can you pause the music?” is still a request to act, not a help question.

No action arming needed

Use the authenticated updated microphone, a fresh wake, default Finn persona and Runtime Awareness ON, while LIVE or deliberately testing in LAB. Help works with action controls disabled or disarmed. It does not add speaker recognition, wake-free control, arbitrary OBS changes or Spotify commands.

Preview first, for free

The private Voice Controls tab's “What Finn can do” preview shows the exact allowed catalog and current prerequisites without AI, microphone admission or action. Cached readiness is not a provider test or a promise an action will succeed. Spoken answers still use normal wake/transcription/reply/voice costs, but no extra action-interpreter call.

Help answers use audio and captions, without Twitch chat echo, Maple banter or shared assistant history. Audio/captions still appear on stream. Help does not open a follow-up window; ask again with a fresh wake. Do not show private live permission previews on stream. No live settings or private dashboard links are published in this guide. Runtime Awareness OFF drops explicit capability questions.

04

Ask about a problem.

Read-only clues, not automatic repairs.

MediaShare

Hey Finn, why isn't the video playing?Hey Finn, check MediaShare.

Finn can explain recent coded browser reports and cached playback state, then suggest a manual check. He does not skip, restart, run a playback test or change settings.

One topic per question. A browser report can concern an older song or a monitor; it is a clue, not a confirmed cause or proof of stream output.

OBS

Hey Finn, is OBS connected?

Finn can describe the last known connection observation and recent coded warnings. Missing evidence stays unknown; a connected source does not prove visible video or audible sound.

No scene switch, probe or repair is authorized by this question. Check the actual Program scene and mixer yourself.

Before asking

Keep Runtime Awareness enabled, use the default Finn persona, and connect your authenticated microphone with voice controls enabled and armed. Use a fresh wake phrase; ordinary wake-free follow-ups do not request diagnostics.

No confirmation is needed for the read-only question. An existing pending action remains pending. If controls disconnect, pause, disarm or lose permission, the diagnostic is dropped; re-arm before repeating.

Free preview, normal reply cost

Doctor's “What Finn can diagnose” card lets you choose MediaShare or OBS and preview the permitted evidence for free. It cannot arm controls, investigate or execute an action.

The spoken question uses one normal Finn response, with tools disabled for that turn and no extra diagnostic model. Usual wake, transcription, response and voice costs remain. Raw logs and private settings are not added to the diagnostic evidence.

05

Test safely

Typed interpretation and a real microphone are different checks.

Free phrase tester

In Voice Controls, open “Try a phrase.” The private “Test phrase” panel interprets typed wording only. It cannot arm, stage, confirm, capture a playback target or run an action. It is not a microphone test.

Enter the request after the wake phrase. Temporary test input and evidence clear when you leave or hide the tab. Switching back never arms anything automatically.

Optional AI preview

“Preview with AI” is a separate explicit interpretation test and may use tokens. It still cannot execute or capture targets. Familiar exact commands use the free grammar; transcription and wake-address checks can still have their usual costs.

Enabled natural interpretation may classify ordinary addressed turns when optional actions are permitted, adding bounded latency/tokens before a normal reply.

Real microphone check

Only arm when changes are intended. Make one supported request, check its proposal/result and the actual state, then disarm. Authorized testing modes are not action dry runs.

A browser completion report does not prove audio reached the OBS mixer or headphones. Delivery-receipt updates add no new spoken commands.

Follow-up rehearsal

With the separate follow-up switch enabled, ask a normal question. Wait for Finn's answer and the dashboard's available countdown, then ask one conversational follow-up. End the conversation or press F11 to check the privacy boundary.

The phrase tester cannot test listening-window timing, speech onset, echo protection or actual OBS/microphone readiness. Those need a deliberate real-audio check.

LIMITS

Still use a fresh wake.

  • Wake-free follow-ups are optional conversation only. Commands, confirmation and bookmarks still need a fresh wake.
  • Only the approved stream presets and the separate Night Sky-on → Finn AFK-on routine and its recorded-break return combine effects. Say other commands separately; extra or unsupported steps reject the whole routine.
  • “Hey Finn, what can you do?” asks about shipped operator voice actions, not every public chat command. Help needs a fresh authenticated wake but no action arming.
  • No arbitrary player URLs, volume/seek controls, shell commands or general model tools are authorized by these requests.
  • Only a separately enabled scoped Night Sky question can accept its offered on/off answer. For other ambiguity, restate the full request with “Hey Finn.” On uncertainty, check the relevant dashboard before trying again.
